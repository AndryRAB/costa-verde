# Costa Verde Hotels - Rattrapage Machine Learning M2

Sujet et données synthétiques pour l'épreuve de rattrapage [ISPM](www.ispm-edu.com). L'objectif est de prédire les annulations de réservations dans neuf communautés autonomes espagnoles, avec évaluation temporelle et calibration des probabilités.

- [Sujet web](./sujet.html)
- [Sujet PDF](./sujet.pdf)
- [Canevas du rapport](./ressources/readme-model.md)

Les ressources (`reservations_train.csv`, `reservations_test.csv`, `sample_submission.csv`, `data_dictionary.csv`) se trouvent dans `ressources/`.

**Remise :** date, horaire et modalité fixés par l'enseignant. Le dossier enseignant et les étiquettes du test ne doivent pas être publiés.

Les profils touristiques et les données sont simulés ; ils ne représentent ni des statistiques réelles ni les comportements de populations.
